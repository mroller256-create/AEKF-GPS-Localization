# AEKF-GPS-Localization

## Adaptive Extended Kalman Filter for GPS Localization

This repository contains the research, simulation, and implementation of an Adaptive Extended Kalman Filter (AEKF) for GPS localization.

## Objectives

The main objectives of this project are:

* To study GPS localization using state-space models.
* To implement an Extended Kalman Filter (EKF).
* To develop an Adaptive Extended Kalman Filter (AEKF).
* To simulate GPS position and measurement errors.
* To evaluate localization accuracy.
* To compare EKF and AEKF performance.

## Technologies

* MATLAB / Simulink

* Digital Control Systems
